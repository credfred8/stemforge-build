# MasterForge FAT ONE

Windows x64 VST3 / standalone one-knob mastering processor by Golden Light Audio.

The FAT knob controls a linked chain: adaptive drive, musical low/mid/high tone shaping,
glue compression, high-band-only stereo widening, parallel soft saturation and a final
safety limiter. The low side image is preserved rather than widened.

At 0% the processing path is effectively bypassed. Higher settings progressively increase
density and apparent loudness.

Install the complete **MasterForge FAT ONE.vst3** folder to:

C:\Program Files\Common Files\VST3

Then rescan plugins in FL Studio.

No processor can guarantee a clean result for every source or rescue a clipped mix.
Leave sensible headroom before the plugin for the best result.
